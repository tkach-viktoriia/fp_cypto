# Bitcoin Trading Activity Classification 🪙

Класифікація торгової активності Bitcoin на основі ринкових даних з використанням методів машинного навчання.

## 📌 Опис проєкту

Проєкт присвячений збору, аналізу та класифікації торгової активності Bitcoin (BTC/USD) за допомогою реальних ринкових даних. Мета — побудувати модель, яка визначає категорію торгової активності на основі цінових та об'ємних показників.

## 📊 Дані

| Параметр | Значення |
|---|---|
| Джерело | Polygon.io API |
| Період | 2021 — теперішній час |
| Оновлення | Автоматичне через API |

## 🔍 Ознаки датасету

| Ознака | Опис |
|---|---|
| Date | Дата торгів |
| Volume | Об'єм торгів |
| VWAP | Середньозважена ціна за об'ємом |
| Open | Ціна відкриття |
| Close | Ціна закриття |
| High | Максимальна ціна за день |
| Low | Мінімальна ціна за день |
| Number of items | Кількість угод за день |
| Category | Цільова змінна |

## ⚙️ Етапи роботи

### 1. Збір даних
- Підключення до Polygon.io API
- Автоматичне збереження даних у CSV
- Перевірка на дублікати при повторному запуску

### 2. Обробка та аналіз даних (EDA)
- Перевірка пропущених значень та дублікатів
- Матриця кореляції
- Візуалізація цін High/Low за останні 30 днів
- Аналіз залежності кількості угод від ціни

### 3. Побудова моделей
- Random Forest
- Bagging (Bootstrap Aggregating)
- Decision Tree
- XGBoost

### 4. Оцінка моделей
- Classification Report (Precision, Recall, F1-score)
- Confusion Matrix

## 🛠️ Інструменти

- Python (pandas, numpy, scikit-learn, XGBoost)
- Matplotlib, Seaborn
- Requests (Polygon.io API)
